# Выбор сервера

> Этот документ описывает исходный FP8/8×H100 маршрут, не требования EXL3 или всех будущих моделей. Переносимый маршрут — [здесь](08-portable-deployment.md).

## Основная конфигурация для репетиции

Ориентир — исторически проверенная конфигурация, а не заявленный минимум:

| Ресурс | Что искать |
|---|---|
| GPU | 8×H100 80 GB, полностью доступны одному процессу, без MIG |
| Соединение GPU | NVLink/NVSwitch внутри одного узла; сверить `nvidia-smi topo -m` |
| RAM | Около 2 TB, как у проверенного узла; учитывать лимит контейнера |
| CPU | Около 96 выделенных потоков исполнения, как в исходном развёртывании |
| Диск данных | Не менее 1 TB свободного места под веса и кэши; желательно запас |
| Системный диск | Отдельный запас под Docker-образ и его распаковку; проверить Docker Root Dir |
| ОС | Linux x86_64, готовый GPU-шаблон с драйвером и Docker/NVIDIA runtime |
| Доступ | SSH по ключу, возможность туннеля и сохранения данных между сессиями |

RAM нужна и для вынесенных на CPU таблиц Engram. Размер checkpoint не равен потреблению VRAM. Расчёт только по сумме видеопамяти не учитывает кэши и временные буферы.

Альтернатива — 4×H200 с NVLink: она указана в [карточке модели](https://huggingface.co/dealignai/DeepSeek-V4.1-Flash-UNCENSORED-FP8), но в этом комплекте не испытана; потребует отдельной репетиции с TP4/EP4. Восемь потребительских GPU без NVLink не считаем эквивалентом основного узла.

## До оплаты

В карточке предложения проверь GPU, топологию, RAM, свободный диск, разрешение Docker и условия сохранности тома. Для Jupyter-контейнера без Docker этот маршрут не подходит: потребуется отдельная установка из исходников. Наличие CUDA в `nvidia-smi` не подтверждает наличие `nvcc`.

Бюджет считай по текущему предложению: `цена узла/час × (загрузка + подготовка + репетиция + запись) + диск + трафик`. Уточни, цена дана за одну карту или весь узел, и продолжается ли оплата диска после остановки. Конкретная цена и доступность предложения здесь не проверены.

Теоретическая загрузка 510,3 GB по каналу 1 Gbit/s займёт минимум около 68 минут; по 10 Gbit/s — около 7 минут. Реальное время больше из-за ограничений источника, сети и диска. Загрузку и первый JIT-запуск лучше сделать до эфира.

## Первые проверки на узле

```bash
uname -m
nvidia-smi
nvidia-smi topo -m
free -h
cat /sys/fs/cgroup/memory.max  # cgroup v2; если файла нет, уточнить лимит у провайдера
cat /sys/fs/cgroup/cpu.max
lsblk -f
df -h
docker info
```

Сверь отсутствие чужих процессов на GPU и фактический лимит RAM. Для выделенного узла отклонение от заказа — повод обратиться к провайдеру до загрузки весов.

Выбери устойчивый каталог данных с правом записи; в примерах `/srv/ds41`. Если провайдер даёт другой mount point, укажи его в `DS41_ROOT`. Не размещай 510 GB весов в маленьком домашнем томе. Используй уже настроенный SSH-ключ; fingerprint сервера сверяй с консолью провайдера, проверку host key не отключай.
